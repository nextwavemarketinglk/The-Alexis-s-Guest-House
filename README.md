# The Alexis's Guest House — Professional Website Concept

## Pages
- Home (`index.html`)
- Rooms
- Gallery
- Explore Negombo
- About
- Contact & direct booking enquiry

## Run locally
Open `index.html` directly, or serve the folder using XAMPP / VS Code Live Server / PHP local server. No build step is required.

## Before publishing
1. Confirm the official WhatsApp number. The public phone number currently used is +94 76 910 3723.
2. Add an owner-approved email address and social links.
3. Replace public listing photos with original high-resolution owner-approved photos.
4. Confirm all room types, amenities, policies and current review/rating snapshots.
5. Replace `https://example.com/` in `sitemap.xml` after the final domain is chosen.
6. Add analytics / Search Console only after owner approval.

## Design direction
Premium coastal hospitality: deep navy, warm sand, muted gold, sea-glass aqua; Playfair Display + DM Sans; responsive animations, parallax hero, reveal transitions, hover tilt, mobile booking bar.

## Notes
This is a sales / client-presentation concept based on public business information researched on 21 Sep 2026. It intentionally avoids inventing an email address, testimonial, fixed room rate, or unverified business result.
